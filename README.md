# GoApsny: Stopgap

Интерактивный конструктор приставных пандусов IDLab (АИС, Сухум). Отдельное приложение, с картой GoApsny и лендингом не смешивается.

Задание: [docs/TZ.md](docs/TZ.md) (ТЗ Алхаса от 2026-11-04).

## Что уже лежит

`cad/` — расчёт пандусов на CAD-движке build123d 0.13.0. Модель строится в 3D, размеры деталей снимаются с неё.

- `ramp_model.py` — ровная площадка: `python ramp_model.py OUT 48 58 98` (высоты порога, мм).
- `ramp_skew.py` — порог разной высоты слева и справа: `python ramp_skew.py OUT 190 160`.
- `sheet_model.py`, `sheet_skew.py`, `render3d.py` — листы A4 и 3D-картинка из модели.

Правила расчёта (Алхас, 2026-10-31 и ТЗ 2026-11-04):

- ширина 900, уклон 1:6, фанера 18, доска 40;
- боковина у порога = порог − 18, основание = порог × 6 (на скосе — по высокой стороне);
- фанера одним листом, все резы 90°, размеры целыми мм;
- внутреннее ребро только при пороге больше 200 мм.

Эти скрипты — расчёт, а не черновик приложения из ТЗ. Черновик, по которому сделан пандус Красного Креста, ещё не перенесён сюда.

## Запуск расчёта

```
pip install -r cad/requirements.txt
cd cad && PYTHONPATH=. python ramp_skew.py out 85 70
```
